# 🏢 منصة التوظيف الذكية — Smart HR & Recruitment Platform

> منصة عربية متكاملة لإدارة التوظيف وتقييم الكفاءات باستخدام الذكاء الاصطناعي، مزودة بلوحة تحكم تفاعلية (Interactive Canvas) ومعاينة حية لكافة الشاشات.
> 
> 🌐 **الرابط الرسمي:** [https://hrjpf.tech](https://hrjpf.tech)

---

## 🌟 مميزات المنصة

- **واجهة مستخدم عربية بالكامل (RTL)** بتصميم حديث يدعم خطوط *Alexandria* و *IBM Plex Sans Arabic*.
- **لوحة تحكم تفاعلية لا نهائية (Infinite Canvas & Gallery View)** لاستعراض كل مراحل التوظيف في مكان واحد مع ميزة التكبير والتصغير وخريطة مصغرة (Minimap).
- **محرك تحليل السير الذاتية بالذكاء الاصطناعي (AI Matching Engine)** لحساب درجات الملاءمة واستخراج المهارات تلقائياً.
- **مسار تقديم واختبار جدارة تفاعلي** يقدم تقييماً فورياً (اجتياز / عدم اجتياز) وتوجيهاً مباشراً للمرشح.
- **نظام متكامل للجنة التوظيف** يشمل المقابلات، جداول المواعيد، رسائل الواتساب التلقائية، وفرز المرشحين.
- **معمارية خفيفة وسريعة (Zero-dependency Web Architecture)** تعمل مباشرة على المتصفح أو عبر أي خادم ويب ثابت (Static Web Server) مثل GitHub Pages أو Vercel.

## 🏗️ البنية والمعمارية التقنية (Architecture)

- **قاعدة البيانات:** PostgreSQL 16 مرفوعة ومستضافة على خادم خاص افتراضي (**VPS**).
- **الواجهات الأمامية:** Vanilla HTML5 / CSS3 / ES6+ مع دعم كامل للعربية (RTL) ولوحة قماشية تفاعلية.
- **إدارة البيئة والأمان:** ملف `.env` لحفظ بيانات اتصال قاعدة البيانات ومفاتيح API في بيئة الخادم دون إتاحتها للمتصفح.
- **التكاملات:** تكامل مع نماذج الذكاء الاصطناعي (OpenAI, Gemini, Claude, DeepSeek) وروابط واتساب الهجينة للمقابلات.

## 🚀 طرق التشغيل السريع (Local Quickstart)

### الطريقة الأولى: التشغيل عبر Node.js (الموصى به)
1. تأكد من تثبيت [Node.js](https://nodejs.org/).
2. شغّل الخادم المدمج بالأمر:
```bash
npm start
```
3. افتح المتصفح على:
```
http://localhost:3000
```

---

### الطريقة الثانية: الفتح المباشر في المتصفح
يمكنك النقر مرتين مباشرة على ملف `index.html` لفتحه في أي متصفح حديث (Chrome / Edge / Safari / Firefox).

## 🌐 النشر المجاني على GitHub Pages (Online Deployment)

لجعل الموقع متاحاً للجميع برابط مباشر عبر الإنترنت:
1. ارفع المشروع إلى مستودع GitHub (اتبع خطوات الرفع بالأسفل).
2. في صفحة المستودع على GitHub، اضغط على **Settings** (الإعدادات).
3. اختر من القائمة الجانبية **Pages**.
4. تحت قسم **Build and deployment**:
   - اختر **Source**: `Deploy from a branch`
   - اختر **Branch**: `main` والمجلد `/ (root)`
   - اضغط **Save**.
5. خلال دقائق سيظهر رابط موقعك المباشر:
   `https://<your-username>.github.io/<repo-name>/`
